Switching the Claude desktop app's sign-in now also works for the app from the older installer.

## New

- **Sign-in switching for the desktop app from the older installer.** Until now baton switched
  only the app that keeps its data in `%LOCALAPPDATA%\Claude-Data`. The app from the older
  installer (installed in `%LOCALAPPDATA%\AnthropicClaude`, its data in `%APPDATA%\Claude`)
  showed "Switching the sign-in is not supported for this kind of Claude desktop app install
  yet". baton now switches it the same way. With *Open the desktop app afterwards* ticked (or
  `--open`), baton opens it as its Start menu entry does.

## Changed

- **Says why switching does not work on this PC.** When baton cannot switch the desktop app here,
  it now says why: no data folder of the app was found (open the app once first), more than one
  folder in `Claude-Data` holds the app's settings, or the app's data folder is a link to
  another place. It changes nothing in any of these cases.

## 한국어

예전 설치 프로그램으로 설치한 Claude 데스크톱 앱에서도 로그인 계정 바꾸기가 됩니다.

**새 기능**
- **예전 설치 프로그램으로 설치한 데스크톱 앱의 로그인 바꾸기.** 지금까지는 데이터를
  `%LOCALAPPDATA%\Claude-Data`에 두는 앱만 바꿀 수 있었습니다. 예전 설치 프로그램으로 설치한 앱(프로그램은
  `%LOCALAPPDATA%\AnthropicClaude`, 데이터는 `%APPDATA%\Claude`)에서는 "이 방식으로 설치된 Claude 데스크톱
  앱은 아직 로그인 전환을 지원하지 않습니다"가 떴습니다. 이제 이 앱도 같은 방식으로 바꿉니다. *바꾼 뒤 데스크톱
  앱 열기*를 켜 두면(또는 `--open`) 시작 메뉴 항목과 같은 방법으로 앱을 엽니다.

**바뀐 점**
- **이 PC에서 계정을 바꿀 수 없는 이유를 알려 줍니다.** 앱 데이터 폴더를 찾지 못했을 때(앱을 먼저 한 번
  여세요), `Claude-Data`에 앱 설정이 든 폴더가 여러 개일 때, 앱 데이터 폴더가 다른 곳을 가리키는 링크일 때
  그 이유를 표시합니다. 어느 경우든 아무것도 바꾸지 않습니다.

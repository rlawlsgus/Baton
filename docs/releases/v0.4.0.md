See what every session is doing from the baton window, and follow a session from your phone with Remote Control.

## New

- **What Claude is doing.** Each running session in the Sessions tab shows whether Claude is
  working, waiting for you, or needs an answer in the session window (a permission question,
  for example), and what it is waiting for.
- **Model and context.** Each session shows its model and how full its context window is.
- **Changed files.** Each session shows how many files changed in its folder, with lines added
  and removed. **Changes** lists them, like the desktop app's changes panel: modified, new,
  deleted and renamed files against the last commit. This needs git (Git for Windows) and a
  folder in a git repository.
- **Remote Control.** *Turn on Remote Control* in the Start dialog lets you see and continue
  the session from the Claude app on your phone or from claude.ai/code. It comes back on by
  itself after a switch. Settings → Advanced can tick it by default for new sessions
  (`baton config remote_control true`). From the command line, use `baton run -- --rc`.

## Good to know

- Remote Control shows a session to the Claude account it runs on. On your phone or at
  claude.ai/code, sign in with that account; the Sessions tab says which one. After a switch
  the session shows on the next account. Putting the account you use on your phone first in
  the account order keeps sessions on it until its limit.
- Remote Control needs a Claude subscription, and an organization can turn it off.

## Fixed

- The Sessions tab said "Working" for any running session. It now says "Running", and what
  Claude itself is doing is shown next to it.

## 한국어

baton 창에서 세션마다 무엇을 하고 있는지 보고, 리모트 컨트롤로 휴대폰에서 세션을 이어 갈 수 있습니다.

**새 기능**
- **Claude가 하고 있는 일.** 세션 탭의 실행 중인 세션마다 Claude가 작업 중인지, 입력을 기다리는지, 세션
  창에서 확인이 필요한지(예: 권한 질문) 보여 주고, 무엇을 기다리는지도 보여 줍니다.
- **모델과 컨텍스트.** 세션마다 모델과 컨텍스트 사용률을 보여 줍니다.
- **바뀐 파일.** 세션마다 폴더에서 바뀐 파일 수와 추가·삭제된 줄 수를 보여 줍니다. **변경사항**을 누르면
  데스크톱 앱의 변경사항 패널처럼, 마지막 커밋 이후 수정·추가·삭제·이름이 바뀐 파일을 목록으로 보여
  줍니다. git(Git for Windows)이 설치되어 있고 폴더가 git 저장소여야 합니다.
- **리모트 컨트롤.** 새 세션 시작에서 *리모트 컨트롤 켜기*를 체크하면 휴대폰의 Claude 앱이나
  claude.ai/code에서 세션을 보고 이어서 쓸 수 있습니다. 계정이 바뀌어도 알아서 다시 켜집니다. 설정 →
  고급 설정에서 새 세션의 기본값으로 정할 수 있습니다(`baton config remote_control true`). 명령줄에서는
  `baton run -- --rc`입니다.

**알아 둘 점**
- 리모트 컨트롤은 세션이 실행 중인 Claude 계정에 세션을 보여 줍니다. 휴대폰이나 claude.ai/code에서 그
  계정으로 로그인해야 보이고, 어느 계정인지는 세션 탭에 나옵니다. 계정이 바뀌면 다음 계정에서 보입니다.
  휴대폰에 로그인해 둔 계정을 계정 순서 맨 위에 두면, 그 계정의 한도가 찰 때까지 세션이 그 계정에 머뭅니다.
- 리모트 컨트롤은 Claude 구독이 필요하고, 조직 설정으로 꺼져 있을 수 있습니다.

**고친 점**
- 세션 탭이 실행 중인 세션을 모두 "작업 중"으로 표시했습니다. 이제 "실행 중"으로 표시하고, Claude가
  실제로 하고 있는 일은 그 옆에 따로 보여 줍니다.

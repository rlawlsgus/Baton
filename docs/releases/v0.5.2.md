The Sessions tab shows less at once, and what changed is easier to read.

## Changed

- **A calmer session row.** Each running session shows its folder and state, then one line
  with the account, a small context meter, the changed lines and Remote Control. The full path,
  start time, model, Remote Control's sign-in hint and the *Open folder* and *Log* buttons are
  under **Details**, which opens and closes per session.
- **Colored changes.** Added lines are green and removed lines are red, in the session row and
  in the changes list. Clicking the changed lines in a row opens that list.
- **Shorter title bar.** The tagline next to "baton" is gone.
- A narrow window puts a session's buttons under it instead of squeezing its text.

## 한국어

세션 탭에 한 번에 보이는 정보를 줄이고, 바뀐 내용을 더 읽기 쉽게 했습니다.

**바뀐 점**
- **간결해진 세션 줄.** 실행 중인 세션마다 폴더와 상태, 그리고 계정, 작은 컨텍스트 막대, 바뀐 줄 수,
  리모트 컨트롤을 한 줄로 보여 줍니다. 전체 경로, 시작 시각, 모델, 리모트 컨트롤 로그인 안내, *폴더 열기*와
  *기록* 버튼은 세션마다 열고 닫는 **자세히**에 들어 있습니다.
- **색으로 보는 변경사항.** 추가된 줄은 초록색, 지운 줄은 빨간색으로 세션 줄과 변경사항 목록에 보여 줍니다.
  세션 줄의 바뀐 줄 수를 누르면 그 목록이 열립니다.
- **짧아진 제목 표시줄.** "baton" 옆의 소개 문구를 없앴습니다.
- 창이 좁으면 세션의 버튼을 글자 밑으로 내려서 글자가 눌리지 않게 했습니다.

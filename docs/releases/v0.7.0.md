An office to watch Claude work in, just for fun.

## New

- **The office.** Turn on *Settings → Show the office (just for fun)* and the window gets an
  **Office** tab. Every Claude Code conversation on your PC is shown live as people at work in an
  isometric office:
  - Claude reads and searches in the library, changes code in the dev room, runs commands in the
    server room (the racks blink faster, and git work gets a git badge), looks things up in the
    search room and plans in the meeting room, where the whiteboard shows its to-do list.
  - When it has a question, or Claude Code waits for your answer, it comes to your desk. After a
    turn it has a coffee in the lounge.
  - A thought shows as a cloud, what it says as a speech bubble, and a failed command as a red
    bubble with a drop of sweat.
  - Subagents come in by elevator in their own outfits (Explore in green with a cap, Plan in
    purple with glasses...), report back to Claude when they are done and go home.
  - When baton moves a session to another account, it is a change of shift: Claude goes home and
    the next account's Claude, in that account's colour, carries on.
  - Each project folder is a floor of the building, and its sessions are listed under it. The
    office follows the latest session (and the new one after `/clear`), or stays on the one you
    pick.
  - The panel on the right shows who is in the office and what they are doing, and an activity
    log. Clicking Claude in a baton session brings up its window.
  - *Pop out* opens the office alone in a window of its own, to keep on another screen.
  - In dark mode it is the office at night.

  It only reads what Claude Code writes down (its session list and transcripts) and works only
  while it is on screen. Conversations outside baton (a terminal, VS Code, the desktop app) show
  too.

## Changed

- New setting: `office` (`baton config office true`), off by default.

## 한국어

Claude가 일하는 모습을 볼 수 있는 사무실이 생겼습니다. 재미로 넣은 기능입니다.

**새 기능**
- **사무실.** *설정 → 사무실 보기 (재미 기능)*를 켜면 창에 **사무실** 탭이 생깁니다. 이 PC의 Claude Code
  대화를 아이소메트릭 사무실에서 일하는 사람들로 실시간으로 보여 줍니다.
  - Claude는 파일을 읽거나 찾을 때 자료실, 코드를 고칠 때 개발실, 명령을 실행할 때 서버실(랙 불빛이 빨라지고,
    git 작업에는 git 표시가 붙습니다), 웹과 도구를 쓸 때 정보검색실, 계획을 세울 때 회의실에 갑니다. 회의실
    화이트보드에는 할 일 목록이 적힙니다.
  - 물어볼 게 생기거나 Claude Code가 내 답을 기다리면 내 자리로 옵니다. 한 차례가 끝나면 라운지에서 커피를
    마십니다.
  - 생각할 때는 구름 말풍선, 말할 때는 말풍선이 뜨고, 명령이 실패하면 식은땀을 흘리며 빨간 말풍선을 띄웁니다.
  - 서브에이전트는 역할마다 다른 옷차림(Explore는 초록 옷에 모자, Plan은 보라 옷에 안경...)으로 엘리베이터를
    타고 출근하고, 일이 끝나면 Claude에게 보고하고 퇴근합니다.
  - baton이 세션을 다른 계정으로 옮기면 교대 근무입니다. 지금 Claude는 퇴근하고, 그 계정 색 옷을 입은 다음
    계정의 Claude가 출근해 일을 이어서 합니다.
  - 프로젝트 폴더마다 건물의 층이 하나씩 있고, 그 층에 세션 목록이 나옵니다. 가장 최근 세션(`/clear` 뒤에는 새
    세션)을 따라가거나, 고른 세션에 머뭅니다.
  - 오른쪽에서 사무실에 누가 있고 무엇을 하는지, 활동 로그를 볼 수 있습니다. baton 세션에서는 Claude를 누르면
    그 세션 창이 앞으로 나옵니다.
  - *따로 띄우기*로 사무실만 별도 창에 띄워 다른 모니터에 둘 수 있습니다.
  - 다크 모드에서는 밤의 사무실이 됩니다.

  Claude Code가 남기는 기록(세션 목록과 대화 기록)을 읽기만 하고, 화면에 보일 때만 동작합니다. baton 밖에서
  연 대화(터미널, VS Code, 데스크톱 앱)도 보입니다.

**바뀐 점**
- 새 설정 `office`(`baton config office true`). 기본값은 꺼짐입니다.

A bug-fix release.

## Fixed

- **"The installed Claude Code CLI is too old" no longer blocks you.** If an old Claude Code
  CLI is installed (for example one installed long ago and never updated), baton now passes it
  over and uses the Claude Code that comes with the Claude desktop app. Settings and
  `baton doctor` show which one was not used and why. This works once the desktop app's Code
  tab has been opened at least once.
- **No more black console window flashing.** The baton window checked Claude Code every minute
  in a way that briefly opened a console window. Those checks now run without any window.

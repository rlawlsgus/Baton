baton can now show any conversation on this PC in the Claude desktop app, or delete it, without opening it in baton first, and it can list every conversation in every account of the desktop app.

## New

- **All conversations on this PC.** The Sessions tab has a new list of every Claude Code
  conversation on this PC: from baton, the desktop app, a terminal and VS Code, newest first, with
  a search. On each one, **Choose desktop app accounts** picks the accounts whose desktop app lists
  it, **Delete conversation** moves it to the Recycle Bin, and **Continue** goes on with it in
  baton. Until now the window offered the desktop app only for baton's own sessions, so a
  conversation had to be run in baton first.
- **Every conversation in every account (optional).** Turn on **Settings → Show every
  conversation in every account of the desktop app** (or `baton config desktop_show_all true`),
  and baton lists every conversation on this PC in the Code tab of every account: baton's accounts
  and every account the desktop app has been signed in to. Whichever account the app is signed in
  to, the same conversations show.
  - New conversations are listed while baton's window is open, within half a minute.
  - An account where you unticked a conversation in baton, or deleted it in the desktop app, stays
    without it. The desktop app's own entries stay as they are, so a conversation the app lists
    already is not listed there twice.
  - A conversation whose folder is gone is not listed, nor the earlier part of a session that went
    on after `/clear`.
  - Turning it off takes off what it listed. What you ticked yourself stays.
  - For the account the desktop app is signed in to, the change shows after you quit the app
    completely (also from its tray icon) and open it again.
  - While it is on, deleting a conversation while the desktop app runs waits until you quit the
    app: every conversation is listed for the account it is signed in to, and the running app
    would write the entry back.

## Changed

- A conversation listed in the desktop app only because every conversation is shown is not added
  to *Recent sessions*; it is in *All conversations on this PC*. A session you showed in the
  desktop app yourself stays in *Recent sessions* as before.
- With many sessions shown in the desktop app, baton's window does far less work in the
  background: it no longer asks Windows for the full name of every path at every look (about a
  millisecond each).

## 한국어

이제 이 PC의 어떤 대화든 baton에서 먼저 열지 않고도 Claude 데스크톱 앱에 표시하거나 삭제할 수 있고, 모든 대화를 데스크톱 앱의 모든 계정에 보이게 할 수도 있습니다.

**새 기능**
- **이 PC의 모든 대화.** 세션 탭에 이 PC의 모든 Claude Code 대화를 보여 주는 목록이 새로 생겼습니다. baton,
  데스크톱 앱, 터미널, VS Code에서 나눈 대화가 최신순으로 나오고, 검색할 수 있습니다. 대화마다 **데스크톱 앱에
  표시할 계정 선택**으로 그 대화를 보여 줄 데스크톱 앱 계정을 고르고, **대화 삭제**로 휴지통에 옮기고, **이어서
  하기**로 baton에서 이어 갈 수 있습니다. 지금까지는 창에서 baton 세션만 데스크톱 앱에 표시할 수 있어서, 먼저
  baton에서 대화를 열어야 했습니다.
- **모든 계정에 모든 대화 보이기 (선택).** **설정 → 데스크톱 앱의 모든 계정에 모든 대화 보이기**를 켜면(또는
  `baton config desktop_show_all true`), baton이 이 PC의 모든 대화를 모든 계정의 Code 탭 목록에 넣습니다. baton
  계정과, 데스크톱 앱이 로그인했던 계정이 모두 들어갑니다. 데스크톱 앱이 어느 계정으로 로그인되어 있든 같은
  대화가 보입니다.
  - 새 대화는 baton 창이 열려 있는 동안 30초 안에 들어갑니다.
  - baton에서 체크를 해제했거나 데스크톱 앱에서 삭제한 계정에는 다시 넣지 않습니다. 데스크톱 앱이 직접 만든
    항목은 그대로 두므로, 앱이 이미 보여 주는 대화를 그 계정에 두 번 넣지 않습니다.
  - 폴더가 없어진 대화와, `/clear` 뒤 이어 간 세션의 앞부분 대화는 넣지 않습니다.
  - 끄면 이 설정으로 넣은 항목을 뺍니다. 직접 체크한 것은 그대로 둡니다.
  - 데스크톱 앱에 로그인된 계정에서는 앱을 완전히 종료(트레이 아이콘에서도)했다가 다시 열면 바뀐 내용이 보입니다.
  - 이 설정을 켠 동안 데스크톱 앱이 실행 중이면, 대화를 삭제하기 전에 앱을 종료해야 합니다. 모든 대화가 로그인된
    계정의 목록에 들어 있고, 실행 중인 앱은 그 항목을 다시 써 넣기 때문입니다.

**바뀐 점**
- 모든 대화를 보이게 한 설정 때문에만 데스크톱 앱에 들어간 대화는 *최근 세션*에 넣지 않습니다. 그런 대화는
  *이 PC의 모든 대화*에서 볼 수 있습니다. 직접 데스크톱 앱에 표시한 세션은 지금처럼 *최근 세션*에 남습니다.
- 데스크톱 앱에 표시한 세션이 많을 때 baton 창이 뒤에서 하는 일이 크게 줄었습니다. 이제 매번 모든 경로의 전체
  이름을 Windows에 묻지 않습니다(한 번에 1밀리초쯤 걸리던 일입니다).

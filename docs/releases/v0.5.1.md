The update check works on office networks.

## Fixed

- **"Could not check for updates: … 403 Forbidden".** baton 0.5.0 asked GitHub's API for
  releases. Without signing in, that API answers only 60 requests an hour per network address,
  and on an office network everyone behind the same address shares them, so the check often
  failed. baton now reads the releases feed of its GitHub page and the release's
  `checksums.txt` instead, which that limit does not cover. Downloading and checking the
  update work as before.

## Good to know

- baton 0.5.0 still checks through the API. If it shows this error, try *Check for updates*
  again later (the limit resets every hour), or download 0.5.1 from the release page once.

## 한국어

회사 네트워크에서도 업데이트 확인이 됩니다.

**고친 점**
- **"업데이트를 확인하지 못했습니다: … 403 Forbidden".** baton 0.5.0은 GitHub API에 릴리스를
  물었습니다. 로그인하지 않으면 이 API는 네트워크 주소 하나에 한 시간 60번까지만 답하고, 회사
  네트워크에서는 같은 주소를 쓰는 사람이 모두 이 한도를 나눠 써서 확인이 자주 실패했습니다. 이제
  baton GitHub 페이지의 릴리스 피드와 그 릴리스의 `checksums.txt`를 읽으므로 이 한도에 걸리지
  않습니다. 내려받기와 체크섬 확인은 그대로입니다.

**알아 둘 점**
- baton 0.5.0은 여전히 API로 확인합니다. 이 오류가 나오면 나중에 *업데이트 확인*을 다시 누르거나
  (한도는 한 시간마다 초기화됩니다), 0.5.1은 릴리스 페이지에서 한 번 직접 받으세요.

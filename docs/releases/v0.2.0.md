When the Claude account you are using hits its usage limit, **baton continues the same Claude Code conversation on your next signed-in account**. You don't copy anything or explain it again. Made for Claude desktop app users on Windows 10/11.

## Highlights

- 🔁 **Same conversation, next account.** baton stops Claude Code cleanly at the limit and starts it again on the next account with the whole conversation, including the prompt that hit the limit. A switch takes about 5–10 seconds.
- 🔐 **Sign in once per account.** Two-factor authentication is included, and every account stays signed in. Claude Code itself signs each account in; baton never reads or stores credentials.
- 🖥️ **A window for desktop app users.** `baton-app.exe` comes in English and Korean, and `baton.exe` has the same features on the command line.
- 📥 **Bring in conversations you already have.** Pick a session from the Claude desktop app, a terminal or VS Code and continue it in baton. If it is still open in the desktop app, baton continues in a copy and leaves the original as it is.
- 🎛️ **You decide when it switches.** baton can ask before every switch (recommended), switch on its own, or switch only when you tell it to.
- 📦 **Nothing else to install.** baton uses the Claude Code that comes with the Claude desktop app. Installing it to the Start menu is optional and needs no administrator rights.

## Download

| File | For |
|---|---|
| `baton_0.2.0_windows_amd64.zip` | most Windows 10/11 PCs |
| `baton_0.2.0_windows_arm64.zip` | ARM PCs (Snapdragon and similar) |

Unzip the file and open `baton-app.exe`. The program is not code-signed, so Windows may show *"Windows protected your PC"* the first time. Choose *More info → Run anyway*. See the [README](https://github.com/rlawlsgus/Baton/blob/main/README.md#getting-started) for the full steps.

> **Important:** Use only accounts you personally own. Anthropic's terms and Usage Policy also forbid using several accounts to get around its limits. Continuing past a usage limit on another account may count as exactly that, and accounts can be suspended without notice. Use baton at your own risk.

## Known limitations

- **Preview.** baton has been tested end to end with the real Claude Code against a mock API. It has not yet been tested across real accounts at a real usage limit. Please report any problem in Issues.
- The program is not code-signed, so expect the SmartScreen warning described above.
- The arm64 build has not been tested on ARM hardware yet.
- Only sessions started from baton switch accounts. A session running in the desktop app's Code tab does not switch; bring it into baton instead.
- Each switch makes the next account read the whole conversation again, which uses part of its quota.

## 한국어

쓰던 Claude 계정이 사용 한도에 걸리면, **baton이 로그인해 둔 다음 계정에서 같은 Claude Code 대화를 이어 갑니다.** 내용을 복사하거나 처음부터 다시 설명할 필요가 없습니다. Windows 10/11의 Claude 데스크톱 앱 사용자를 위한 프로그램입니다.

**주요 기능**
- 🔁 **같은 대화를 다음 계정에서.** 한도에 걸리면 Claude Code를 안전하게 멈추고, 다음 계정에서 대화 전체를 가지고 다시 시작합니다. 한도에 걸린 그 질문도 사라지지 않습니다. 전환은 5~10초쯤 걸립니다.
- 🔐 **로그인은 계정마다 한 번.** 2단계 인증을 포함해 한 번만 로그인하면 계속 유지됩니다. 로그인은 Claude Code가 직접 하며, baton은 인증 정보를 읽거나 저장하지 않습니다.
- 🖥️ **데스크톱 앱 사용자를 위한 창.** `baton-app.exe`는 한국어와 영어를 지원하고, `baton.exe`로 명령줄에서도 같은 기능을 쓸 수 있습니다.
- 📥 **기존 대화 가져오기.** 데스크톱 앱, 터미널, VS Code에서 하던 세션을 골라 baton에서 이어 갑니다. 데스크톱 앱에서 아직 열려 있는 대화는 사본으로 이어 가고, 원래 대화는 그대로 둡니다.
- 🎛️ **전환 방식은 내가 정합니다.** 전환할 때마다 묻거나(권장), 알아서 전환하거나, 직접 지시할 때만 전환하게 할 수 있습니다.
- 📦 **따로 설치할 것 없음.** 데스크톱 앱에 들어 있는 Claude Code를 그대로 씁니다. 시작 메뉴 설치는 선택이며 관리자 권한이 필요 없습니다.

**받기:** 대부분의 PC는 `baton_0.2.0_windows_amd64.zip`, ARM PC(Snapdragon 등)는 `..._arm64.zip`을 받습니다. 압축을 풀고 `baton-app.exe`를 엽니다. 서명되지 않은 프로그램이라 처음에 "Windows의 PC 보호" 창이 뜰 수 있습니다. *추가 정보 → 실행*을 누르세요. 자세한 순서는 [한국어 README](https://github.com/rlawlsgus/Baton/blob/main/README.ko.md#시작하기)에 있습니다.

> **중요:** 본인 소유의 계정만 쓰세요. Anthropic 약관과 이용 정책은 여러 계정으로 제한을 피하는 것을 금지합니다. 한도에 걸린 뒤 다른 계정으로 이어 쓰는 것이 그런 행위로 판단될 수 있고, 계정이 예고 없이 정지될 수 있습니다. 본인 판단과 책임으로 사용하세요.

**알려진 제한**
- **프리뷰 버전입니다.** 실제 Claude Code와 가짜 API로 전 과정을 테스트했지만, 실제 계정이 실제 한도에 걸리는 상황은 아직 테스트하지 않았습니다. 문제가 있으면 Issues에 알려 주세요.
- 코드 서명이 없어서 위의 SmartScreen 경고가 나옵니다.
- arm64 빌드는 아직 실제 ARM 기기에서 테스트하지 않았습니다.
- baton에서 시작한 세션만 계정을 전환합니다. 데스크톱 앱의 Code 탭에서 실행 중인 세션은 전환되지 않으니 '기존 대화 가져오기'로 가져오세요.
- 전환할 때마다 다음 계정이 대화 전체를 다시 읽으므로, 그 계정의 한도를 일부 씁니다.

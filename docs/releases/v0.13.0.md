The Accounts tab now keeps every account's 5-hour and weekly limits current, also what you used in the Claude desktop app or on claude.ai, without a baton session on it.

## New

- **Usage between sessions.** Until now an account's usage showed only once a baton session had
  run on it, as of that moment. Now baton asks the account's own Claude Code for it, as its
  `/usage` command does:
  - when the window opens, and on **Check sign-ins** (or `baton doctor`), for every account;
  - when you open the Accounts tab, for the accounts whose numbers are older than five minutes;
  - after a reply in the Claude desktop app (or another Claude Code of your own setup) ends, for
    that Claude account.

  The limits belong to the account, so this includes what the desktop app and claude.ai used. A
  running baton session keeps its account current through its status line, as before.
- **Cheap, and nothing in the background.** Each time, Claude Code runs for a few seconds without
  a window and without a prompt, so it uses none of the limits (about a second of CPU, and a
  short peak of memory while Claude Code starts). Nothing is asked on a timer: only at the moments
  above, one account at a time, and an account at most once a minute.
- baton still never reads an account's sign-in: Claude Code reads its own.

## Fixed

- **An older Claude Code in the desktop app.** Claude Code before about 2.1.325 does not say what
  a desktop app session is doing (it says so only in a terminal). With such a version,
  *switching the desktop app while it runs* said "baton cannot tell now whether it is working
  (try again in a moment)" for every open session, and trying again never helped. It now says
  that this Claude Code does not say what it is doing, and to quit the app yourself (also from
  its tray icon) before switching. The usage check after a reply notices the reply's end by the
  conversation file instead, with these versions.

## 한국어

이제 계정 탭이 모든 계정의 5시간·주간 한도를 baton 세션이 없어도 최신으로 보여 줍니다. Claude 데스크톱 앱이나 claude.ai에서 쓴 양도 포함됩니다.

**새 기능**
- **세션이 없어도 사용량을 갱신합니다.** 지금까지는 그 계정으로 baton 세션을 쓴 뒤에, 그 시점 기준으로만
  보였습니다. 이제 baton이 그 계정의 Claude Code에 `/usage` 명령처럼 사용량을 묻습니다.
  - 창을 열 때와 **로그인 상태 확인**(또는 `baton doctor`) 때: 모든 계정
  - 계정 탭을 열 때: 값이 5분보다 오래된 계정
  - Claude 데스크톱 앱(또는 평소 쓰는 다른 Claude Code)에서 답변이 끝났을 때: 그 Claude 계정

  한도는 계정 단위라 데스크톱 앱과 claude.ai에서 쓴 양도 포함됩니다. 실행 중인 baton 세션은 지금처럼
  상태 표시줄로 그 계정의 사용량을 갱신합니다.
- **가볍고, 뒤에서 계속 묻지 않습니다.** 물을 때마다 Claude Code가 창 없이 몇 초 실행되며, 프롬프트를
  보내지 않으므로 한도를 쓰지 않습니다(CPU 1초 안팎, Claude Code가 뜨는 동안 잠깐 메모리를 씁니다).
  정해진 주기로 묻지 않고 위의 때에만, 한 번에 한 계정씩, 같은 계정은 1분에 한 번까지만 묻습니다.
- baton은 여전히 계정의 로그인 정보를 읽지 않습니다. Claude Code가 자기 로그인을 읽습니다.

**고친 점**
- **데스크톱 앱의 Claude Code가 오래된 버전일 때.** 2.1.325쯤보다 오래된 Claude Code는 데스크톱 앱 세션이 무엇을
  하는지 알려 주지 않습니다(터미널에서만 알려 줍니다). 그런 버전에서는 *실행 중인 데스크톱 앱의 로그인 바꾸기*가
  열린 세션마다 "작업 중인지 지금은 알 수 없음(잠시 뒤 다시 시도하세요)"라고 했고, 다시 시도해도 소용이
  없었습니다. 이제 이 Claude Code가 작업 상태를 알려 주지 않는 버전이라고 밝히고, 앱을 직접 종료(트레이
  아이콘에서도)한 뒤 바꾸라고 안내합니다. 답변이 끝난 뒤의 사용량 확인은 이런 버전에서 대화 파일로 답변이
  끝난 것을 알아챕니다.

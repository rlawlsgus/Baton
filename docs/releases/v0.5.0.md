baton can now update itself from GitHub, and bringing in a conversation that is open elsewhere tells you how to keep it one conversation.

## New

- **Updates.** **Help → Update baton** asks GitHub for the newest release and shows what
  changed. *Update to …* downloads it, checks it against the release's `checksums.txt`,
  installs it to the Start menu and opens the new window. Your accounts, settings and
  conversations stay as they are. While the window is open it also looks every few hours and
  shows a banner when a new release is out; Help → Update baton or
  `baton config check_updates false` turns that off. From the command line:
  `baton update`, or `baton update --check` to only look.
- **Conversations that are open elsewhere.** When you bring in a conversation that is still
  open in the Claude desktop app, in a terminal or in VS Code, baton says where it is open and
  how to close it there, with a *Check again* button. If you go on while it is still open, the
  button says *Continue in a copy*, and baton explains that the copy goes on apart from the
  original. `baton sessions` and `baton resume` say the same.

## Good to know

- 0.4.x has no update button, so get this version from the release page as before. From
  0.5.0 on, baton updates itself.
- An update waits until no session runs and the windows baton opened are closed, because
  those use baton's programs.
- A baton run from the unzipped folder installs the update to the Start menu
  (`%LOCALAPPDATA%\Programs\baton`) and opens from there.
- A conversation brought in without a copy is the same conversation in baton and in the
  desktop app: both use the same file. Use it on one side at a time; whichever side opens it
  next continues from everything said on the other.

## 한국어

baton이 GitHub에서 스스로 업데이트할 수 있고, 다른 곳에서 열려 있는 대화를 가져올 때 같은 대화로 이어 가는
방법을 알려 줍니다.

**새 기능**
- **업데이트.** **도움말 → baton 업데이트**에서 GitHub의 최신 릴리스를 확인하고 바뀐 점을 보여 줍니다.
  *…(으)로 업데이트*를 누르면 내려받아 그 릴리스의 `checksums.txt`와 비교한 뒤 시작 메뉴에 설치하고 새 창을
  엽니다. 계정, 설정, 대화는 그대로입니다. 창이 열려 있는 동안 몇 시간마다 확인해서 새 버전이 나오면
  배너로 알려 줍니다. 도움말 → baton 업데이트나 `baton config check_updates false`로 끌 수 있습니다.
  명령줄에서는 `baton update`, 확인만 하려면 `baton update --check`를 실행합니다.
- **다른 곳에서 열려 있는 대화.** Claude 데스크톱 앱, 터미널, VS Code에서 아직 열려 있는 대화를 가져오면
  어디에서 열려 있는지와 그쪽을 닫는 방법을 알려 주고, *다시 확인* 버튼을 보여 줍니다. 열려 있는 채로
  계속하면 버튼이 *사본으로 이어 가기*로 바뀌고, 사본은 원래 대화와 따로 진행된다고 알려 줍니다.
  `baton sessions`와 `baton resume`도 같은 내용을 알려 줍니다.

**알아 둘 점**
- 0.4.x에는 업데이트 버튼이 없으니, 이번 버전은 지금처럼 릴리스 페이지에서 받으세요. 0.5.0부터는 baton이
  스스로 업데이트합니다.
- 업데이트는 실행 중인 세션이 없고 baton이 연 창이 모두 닫혀 있을 때 진행됩니다. 그것들이 baton 프로그램을
  쓰고 있기 때문입니다.
- 압축을 푼 폴더에서 실행 중인 baton은 업데이트를 시작 메뉴(`%LOCALAPPDATA%\Programs\baton`)에 설치하고
  거기서 다시 엽니다.
- 사본이 아니게 가져온 대화는 baton과 데스크톱 앱에서 같은 대화이고, 같은 파일을 씁니다. 한 번에 한쪽에서만
  쓰세요. 다음에 여는 쪽이 다른 쪽에서 나눈 대화까지 모두 이어 갑니다.

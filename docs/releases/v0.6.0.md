Sessions now tell you when they need you, come back after a restart, and can be kept on
the accounts a folder should use.

## New

- **Windows notifications.** A session lets you know when it switched accounts, when every
  account is limited, when baton or Claude Code waits for your answer in the session window,
  when it ended unexpectedly, and when a response that took over 30 seconds is done. Clicking
  one brings up that session's window. They come with the baton window closed too, and the
  frequent ones stay quiet while you are looking at the session window. Choose all, important
  only or off in **Settings → Windows notifications**, and try them with *Send a test
  notification*.
- **Reopen cut-off sessions.** When Windows restarts, shuts down or signs you out under a
  session, or a session stops without being ended (a crash, a power cut), the Sessions tab
  offers to reopen it for 7 days: in its folder, on the account it was on if that one can be
  used, with the same Claude Code options and permission mode. A session that was working
  carries on with its task. *Reopen all* brings back every one at once; *Dismiss* takes one
  off the list. From the command line: `baton status` lists them and
  `baton run --restore <run>` reopens one.
- **Accounts per folder.** A folder rule keeps the sessions in a folder, and the folders under
  it, on the accounts you choose: they start and switch only among those, and the window
  offers only those. With one account a session never moves, so a company repository can stay
  on the company account. Set rules in **Settings → Accounts per folder**, or with
  `baton rules`. A running session takes on a changed rule only if it is stricter.
- **Show window.** Each running session in the Sessions tab has a *Show window* button that
  brings its Claude Code window to the front (in Windows Terminal, the terminal window that
  holds it).
- **No sleep while Claude works.** While a session works, or baton moves it or waits for a
  limit to reset, the PC does not go to sleep by itself. The screen can still turn off, and
  Sleep or closing a laptop's lid still works. You can turn this off in Settings.

## Changed

- New commands and options: `baton rules`, `baton run --restore <run>`, and the settings
  `notifications` (`all`, `important` or `off`) and `keep_awake`. `baton status` also lists
  sessions that were cut off.
- The uninstall also removes baton's notification registration.

## 한국어

세션이 내 확인이 필요할 때 알려 주고, PC를 다시 시작한 뒤에도 이어서 열 수 있으며, 폴더마다 쓸 계정을 정할 수
있습니다.

**새 기능**
- **Windows 알림.** 세션이 계정을 바꿨을 때, 모든 계정이 한도에 걸렸을 때, baton이나 Claude Code가 세션
  창에서 답을 기다릴 때, 세션이 예기치 않게 끝났을 때, 30초 넘게 걸린 응답이 끝났을 때 알려 줍니다. 알림을
  누르면 그 세션 창이 앞으로 나옵니다. baton 창을 닫아도 알림이 오고, 자주 오는 알림은 세션 창을 보고 있는
  동안에는 오지 않습니다. **설정 → Windows 알림**에서 모두, 중요한 것만, 끄기 중에 고르고 *알림 보내 보기*로
  확인할 수 있습니다.
- **끊긴 세션 다시 열기.** Windows가 다시 시작되거나 종료되거나 로그아웃되면서 세션이 끊기거나, 끝내지 않은
  세션이 멈추면(오류, 정전) 세션 탭에서 7일 동안 다시 열 수 있습니다. 원래 폴더에서, 원래 계정을 쓸 수 있으면
  그 계정에서, 같은 Claude Code 옵션과 권한 모드로 엽니다. 작업 중이던 세션은 하던 일을 계속합니다.
  *모두 다시 열기*로 한 번에 열고, *지우기*로 목록에서 뺄 수 있습니다. 명령줄에서는 `baton status`로 확인하고
  `baton run --restore <run>`으로 엽니다.
- **폴더별 계정.** 폴더 규칙을 두면 그 폴더와 그 안의 폴더의 세션은 고른 계정에서만 시작하고 전환하며, 창에서도
  그 계정만 고를 수 있습니다. 계정을 하나만 고르면 세션이 다른 계정으로 옮겨 가지 않으므로, 회사 저장소를 회사
  계정에만 둘 수 있습니다. **설정 → 폴더별 계정**이나 `baton rules`로 정합니다. 실행 중인 세션에는 더 엄격해지는
  변경만 적용됩니다.
- **창 보기.** 세션 탭에서 실행 중인 세션마다 *창 보기* 버튼이 생겨, 그 세션의 Claude Code 창을 앞으로
  가져옵니다(Windows Terminal에서는 세션이 들어 있는 터미널 창).
- **Claude가 작업하는 동안 절전 안 함.** 세션이 작업하거나, baton이 세션을 옮기거나 한도가 풀리기를 기다리는
  동안에는 PC가 저절로 절전 모드로 들어가지 않습니다. 화면은 꺼질 수 있고, 직접 절전하거나 노트북 덮개를
  닫으면 잠듭니다. 설정에서 끌 수 있습니다.

**바뀐 점**
- 새 명령과 옵션: `baton rules`, `baton run --restore <run>`, 설정 `notifications`(`all`, `important`, `off`)와
  `keep_awake`. `baton status`에 끊긴 세션도 나옵니다.
- 제거할 때 baton의 알림 등록도 지웁니다.

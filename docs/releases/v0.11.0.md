baton can now switch the Claude desktop app's sign-in while the app is running: it quits the app, switches it, and opens it again.

## New

- **Switch the desktop app's sign-in while it runs.** Until now baton refused to switch while the
  desktop app was running, and you had to quit it completely yourself (also from its tray icon).
  Now **Switch the desktop app to this account** and **Add an account to the desktop app** work
  while it runs: baton asks first, then quits the app, switches it, and opens it again. From the
  command line, add `--quit`: `baton desktop login use work --quit`.
  - **Not while it is working.** baton does not quit the app while, in one of the Claude Code
    sessions the app runs, Claude is working on a reply or waiting for your answer, or something
    runs in the background: a command (or a Monitor), an agent or a workflow, or a `/loop` or a
    scheduled job that is still to wake it. It lists those sessions and what each is doing, and
    changes nothing. Stop that work, or let it finish, and try again.
  - **The way Windows closes a program.** baton asks the app to quit as Windows does before an
    update, so the app saves what it keeps and quits by itself. If it does not quit within a
    minute (it may be asking you something), baton changes nothing and asks you to quit it
    yourself.
  - **The app opens again either way.** Once baton has quit the app, it opens it again even if
    the switch then does not go ahead. The app is then on the account it was on.
  - Nothing is quit for a switch that would be refused anyway: switching to the account the app is
    already on, or to one baton keeps no sign-in for.

## Changed

- After **Add an account to the desktop app**, you no longer need to quit the app after signing in
  to the other account. Switch between them right away; baton quits the app for the switch.

## 한국어

이제 Claude 데스크톱 앱이 실행 중이어도 로그인 계정을 바꿀 수 있습니다. baton이 앱을 종료하고 계정을 바꾼 뒤 다시 엽니다.

**새 기능**
- **실행 중인 데스크톱 앱의 로그인 바꾸기.** 지금까지는 데스크톱 앱이 실행 중이면 계정 바꾸기를 거절해서, 직접
  앱을 완전히 종료(트레이 아이콘에서도)해야 했습니다. 이제 **데스크톱 앱을 이 계정으로 바꾸기**와 **데스크톱 앱에
  계정 추가**를 앱이 실행 중일 때도 쓸 수 있습니다. baton이 먼저 물어본 뒤 앱을 종료하고, 계정을 바꾸고, 다시
  엽니다. 명령줄에서는 `--quit`을 붙이세요: `baton desktop login use work --quit`.
  - **작업 중일 때는 종료하지 않습니다.** 앱이 실행하는 Claude Code 세션 가운데 Claude가 답을 작성하고 있거나 내
    답을 기다리는 세션, 또는 백그라운드 작업이 돌고 있는 세션이 있으면 앱을 종료하지 않습니다. 백그라운드 작업에는
    명령(Monitor 포함), 에이전트, 워크플로, 아직 깨어날 예정인 `/loop`나 예약 작업이 모두 들어갑니다. 이때는 그
    세션들과 각각 무엇을 하고 있는지 알려 주고, 아무것도 바꾸지 않습니다. 작업을 멈추거나 끝날 때까지 기다린 뒤
    다시 시도하세요.
  - **Windows가 프로그램을 닫는 방식.** Windows가 업데이트 전에 프로그램을 닫을 때와 같은 방식으로 종료를 요청하므로,
    앱이 보관할 것을 저장하고 스스로 종료합니다. 1분 안에 종료되지 않으면(앱이 무언가를 묻고 있을 수 있습니다)
    아무것도 바꾸지 않고, 직접 종료해 달라고 안내합니다.
  - **어느 경우든 앱을 다시 엽니다.** baton이 앱을 종료한 뒤에는, 계정 바꾸기가 진행되지 않더라도 앱을 다시 엽니다.
    이때 앱은 원래 계정 그대로입니다.
  - 어차피 거절될 전환을 위해서는 앱을 종료하지 않습니다. 이미 그 계정인 경우나 보관한 로그인이 없는 계정으로
    바꾸려는 경우가 그렇습니다.

**바뀐 점**
- **데스크톱 앱에 계정 추가** 뒤 다른 계정으로 로그인하고 나서 앱을 종료하지 않아도 됩니다. 바로 계정을 바꾸면
  baton이 그때 앱을 종료합니다.

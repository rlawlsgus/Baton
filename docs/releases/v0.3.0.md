See how much of each account's limits you have used, and choose which Claude Code baton runs.

## New

- **Each account's 5-hour and weekly usage.** The Accounts tab shows, for every account, how
  much of its 5-hour and weekly limits is used and when each resets. `baton list` has a new
  USAGE column.
- **Account and usage under the prompt.** Every baton session now shows its account and usage
  in Claude Code's status line, for example `baton · work · 5h 34% · week 12%`.
- **Choose which Claude Code to use.** Settings → Advanced → *Claude Code to use* can now be set
  to *Always the one inside the Claude desktop app*, or run `baton config claude_path desktop`.
  It follows the app's updates by itself.

## Good to know

- Usage comes from the sessions. Claude Code reports it to a session's status line, and only
  for a Claude subscription. An account shows its usage once a baton session has run on it,
  as of that moment. baton never asks Anthropic for it.
- If you set a status line of your own (`statusLine` in your Claude Code settings), baton leaves
  it as it is and records no usage for those sessions.
- Sessions still open in a Claude Code window of their own, not inside the desktop app. baton
  has to run Claude Code itself to move a session between accounts, and the desktop app has
  one sign-in of its own that baton does not touch. The new setting only picks which
  `claude.exe` runs.

## Known limitations

- The usage display was built and tested against the status line data of Claude Code 2.1.309.
  The test accounts sign in with API keys, which get no usage data, so it has not yet been
  checked with a real subscription. Please report it in Issues if no numbers appear after a
  session.

## 한국어

계정마다 한도를 얼마나 썼는지 보고, baton이 실행할 Claude Code를 고를 수 있습니다.

**새 기능**
- **계정별 5시간·주간 사용량.** 계정 탭에서 계정마다 5시간 한도와 주간 한도를 얼마나 썼는지, 언제
  초기화되는지 보여 줍니다. `baton list`에도 USAGE 칸이 생겼습니다.
- **프롬프트 아래에 계정과 사용량.** baton 세션마다 Claude Code의 상태 표시줄에 계정과 사용량이
  나옵니다. 예: `baton · work · 5시간 34% · 주간 12%`
- **사용할 Claude Code 고르기.** 설정 → 고급 설정 → *사용할 Claude Code*에서 *항상 Claude 데스크톱 앱에
  들어 있는 것*을 고를 수 있습니다. 명령줄에서는 `baton config claude_path desktop`입니다. 앱이
  업데이트되어도 알아서 따라갑니다.

**알아 둘 점**
- 사용량은 세션에서 옵니다. Claude Code가 세션의 상태 표시줄에 넘겨 주는 값이며, Claude 구독 계정에만
  있습니다. 그래서 그 계정으로 baton 세션을 한 번 쓴 뒤부터, 그 시점 기준으로 표시됩니다. baton이
  Anthropic에 따로 묻지는 않습니다.
- 직접 설정한 상태 표시줄(Claude Code 설정의 `statusLine`)이 있으면 baton은 그대로 두고, 그 세션의
  사용량은 기록하지 않습니다.
- 세션은 여전히 데스크톱 앱 안이 아니라 별도의 Claude Code 창에서 열립니다. 세션을 계정 사이에서
  옮기려면 baton이 Claude Code를 직접 실행해야 합니다. 데스크톱 앱에는 앱 자체의 로그인이 하나 있고,
  baton은 그것을 건드리지 않습니다. 새 설정은 어떤 `claude.exe`를 실행할지만 정합니다.

**알려진 제한**
- 사용량 표시는 Claude Code 2.1.309가 상태 표시줄에 넘기는 데이터에 맞춰 만들고 테스트했습니다. 테스트
  계정은 API 키로 로그인해서 사용량 데이터를 받지 않으므로, 실제 구독 계정으로는 아직 확인하지
  못했습니다. 세션을 쓴 뒤에도 숫자가 나오지 않으면 Issues에 알려 주세요.

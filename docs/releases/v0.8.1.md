Buttons say what they do in full: none of them ends in "…" any more.

## Fixed

- **Buttons that looked cut off.** Four labels ended in "…", the old sign for a button that opens
  a dialog, which read as text cut short. Each now says in full what it does:
  - *Desktop app…* (on a running session under *Details*, and in *Recent sessions*) is now
    **Choose desktop app accounts**.
  - The first line of a running session's account list, *Switch account…*, is now
    **Switch account**.
  - *Browse…*, where you pick a folder, is now **Browse**.
  - *Uninstall…* in *Help* is now **Uninstall**.

  What they do is unchanged. The README's pictures show the new labels.

## 한국어

버튼이 하는 일을 끝까지 적어 보여 줍니다. 이제 "…"로 끝나는 버튼은 없습니다.

**고친 점**
- **잘린 것처럼 보이던 버튼.** 버튼 네 개가 "…"로 끝났습니다. 누르면 창이 열린다는 옛 표시였지만, 글이
  잘린 것처럼 보였습니다. 이제 각각 하는 일을 끝까지 적습니다.
  - *데스크톱 앱 표시…*(실행 중인 세션의 *자세히* 안, *최근 세션*)는 **데스크톱 앱에 표시할 계정 선택**이
    되었습니다.
  - 실행 중인 세션의 계정 목록 첫 줄 *다른 계정으로…*는 **다른 계정으로 전환**이 되었습니다.
  - 폴더를 고르는 *찾아보기…*는 **찾아보기**가 되었습니다.
  - *도움말*의 *제거…*는 **제거**가 되었습니다.

  하는 일은 그대로입니다. README의 그림도 새 이름으로 바꿨습니다.

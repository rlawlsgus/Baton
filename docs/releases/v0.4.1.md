Removing an account or uninstalling baton no longer deletes your conversations.

## Fixed

- **Conversations are kept.** Conversations that started in baton are stored in the profile
  of the account they started on, and until now uninstalling baton deleted them with
  everything else; `baton remove --force` did the same for one account. Now both first move
  those conversations into your own Claude Code (`%USERPROFILE%\.claude`), with their tool
  results, subagents, memory and `/rewind` checkpoints, so `claude --resume` opens them
  again. A file you already have there is never overwritten; a different file with the same
  name is kept next to it as `<name> (baton <account>)`. If anything cannot be moved, nothing
  is deleted.
- `baton remove` no longer refuses an account with conversations, and no longer needs
  `--force` (the option is still accepted). The window's *Remove with conversations* button is
  gone, since conversations are always kept.

## Good to know

- Your own Claude Code setup and the Claude desktop app's sessions were never touched by an
  uninstall, and still are not.

## 한국어

계정을 삭제하거나 baton을 제거해도 이제 대화가 지워지지 않습니다.

**고친 점**
- **대화를 보존합니다.** baton에서 시작한 대화는 그 대화를 시작한 계정의 프로필에 저장됩니다. 지금까지는
  baton을 제거하면 이 대화도 다른 데이터와 함께 지워졌고, `baton remove --force`도 그 계정의 대화를
  지웠습니다. 이제 둘 다 먼저 이 대화를 평소 Claude Code 폴더(`%USERPROFILE%\.claude`)로 옮깁니다. 도구
  결과, 서브에이전트, 메모리, `/rewind` 체크포인트도 함께 옮기므로 `claude --resume`으로 다시 열 수
  있습니다. 그 폴더에 이미 있는 파일은 덮어쓰지 않고, 이름은 같지만 내용이 다른 파일은
  `<이름> (baton <계정>)`으로 옆에 둡니다. 하나라도 옮기지 못하면 아무것도 지우지 않습니다.
- `baton remove`는 대화가 있는 계정도 거절하지 않고, `--force`가 필요 없습니다(옵션은 그대로 받습니다).
  대화를 항상 보존하므로 창의 *대화까지 삭제* 버튼은 없앴습니다.

**알아 둘 점**
- 평소 쓰던 Claude Code 설정과 Claude 데스크톱 앱의 세션은 원래부터 제거할 때 건드리지 않았고, 지금도
  그대로입니다.
